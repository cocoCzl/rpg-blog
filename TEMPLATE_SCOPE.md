# Template Scope

`rpg-blog` is a static personal blog template with a polished pixel JRPG guild menu interface.

## In Scope

- Astro static blog template
- Save Board Homepage
- Command Menu Navigation
- Character Slot and Profile
- Quest Board for the pinned Journal Entry
- Save Slots for recent Journal Entries
- Chapters and Clues browse surfaces
- Optional Inventory Toolkit
- Dark JRPG Menu Palette and atmospheric guild backdrop
- Bilingual Chinese/English UI chrome
- RSS, sitemap, robots, Open Graph metadata, and Docker deployment packages
- React integration and Pxlkit-based pixel icon rendering when it improves visual completion

## Out Of Scope

- Playable RPG systems
- Controllable characters
- Combat, levels, experience, achievements, or real inventory state
- Accounts, login, comments, databases, or backend APIs
- Admin dashboards
- Search unless separately requested
- Bilingual Journal Entry authoring workflow
- Copyrighted game assets or direct copying from existing games

The template should pass the Three-Second RPG Menu Test: a first-time visitor should recognize a polished pixel RPG menu interface for a personal blog within three seconds.
